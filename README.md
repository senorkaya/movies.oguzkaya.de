# movies.oguzkaya.de

Meine Filmempfehlungen für Freunde. Statische Seite, gehostet über GitHub Pages.

## Film hinzufügen

1. Poster in `posters/` ablegen.
2. Eintrag in `movies.json` ergänzen (`title`, `year`, `director`, `poster`, `rating` von 0–10, `review` als Freitext).
3. Committen und pushen — GitHub Pages deployed automatisch.

## Domain

`CNAME` zeigt auf `movies.oguzkaya.de`. DNS bei Hover: CNAME `movies` → `senorkaya.github.io`.
